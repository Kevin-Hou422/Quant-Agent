# 主机待机与每日任务补跑

调度器运行时会向 Windows 申请阻止空闲待机；请求只在调度器进程中的专用线程存活时有效，不能防止合盖、电源耗尽、人工休眠或关机。上线预检检查交流供电、合盖、空闲睡眠和休眠设置，读取失败时不通过。电源设置改变后应重新预检。

运行期间的时间间隔异常会产生严重告警，并尽力写入执行库；墙钟跳变或进程长时间无法运行也可能触发该告警，它不是系统休眠事件的证明。进程停止期间无法实时监测或发送告警；盘中停机或休眠期间不能执行巡检、日亏检查和熔断维护，恢复后应先核对账户、订单和告警。

常规定时、重试及补跑共用跨进程每日任务锁，锁目录由 `ACCOUNT_LOCK_DIR` 或默认机器共享目录决定；多部署需使用同一锁目录。该锁不替代券商账户锁、认领、对账和订单去重，也不约束直接绕过调度器调用管线的其他入口。

补跑在常规定时和重试时间之后检查最近已收盘交易日，截止于下一交易日开盘前 15 分钟。超过时限会告警，不追补。每个决策日最多尝试 6 次；到达上限后等待人工检查。只有 PIT 数据到达决策日且管线报告执行成功才记录完成；失败、执行受阻、提交异常或证据写入失败不会因数据已到达而被记为完成。数据已存在时重跑仍需通过执行层的认领、对账和去重；未知订单状态须处理后才能安全恢复。

测试使用隔离环境和替身；真实机器的供电、合盖、睡眠、锁屏通知、OpenD 重连及交易时段仍需现场验证，不能因此认定无人值守已就绪。
